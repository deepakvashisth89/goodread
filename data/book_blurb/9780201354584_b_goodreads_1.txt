Macromedia Fireworks 2 is an all-inclusive tool for producing Web graphics and animations. Fireworks offers users the ability to create a graphic and add text, optimize the color palette for the Web, animate the graphic, create links and image maps, and finally preview the completed graphic. Now shipping with Director 7, Fireworks 2 promises to take the Web graphics world by storm with features like a powerful graphics tool set, HTML linking and Live Effects, which update automatically. Fireworks 2 for Windows and Visual QuickStart Guide introduces novice and experienced Web designers to this powerful technology, using a practical, step-by-step approach that makes it easy to get started.

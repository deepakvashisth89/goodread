A completed20roleplaying game that handles any contemporary fantasy theme.This product is designed to be the sole core rulebook for all modern roleplaying game settings using thed20System, which is the basic rules system for theDungeons & Dragons® roleplaying game. Thematically aligned with the highly popular heroic fantasy and horror genres, this book will build on the strength of the growingd20System while attracting new players. The product contains everything needed to run an entire campaign, as well as four campaign models and adventure hooks to add to existing campaigns.
